# 墨锭试磨室

墨锭建档、试磨首录与双人复核闭环。

## 运行

```bash
npm start
```

访问 `http://localhost:3037`。数据保存在 `data/ink-stick-testing.json`。

## 复核闭环规则

- 状态：`待试磨 → 待复核 → 已试磨 / 重点观察`，状态由试磨轮次自动推导，不能手工修改。
- 每锭同时只能有一轮未结束试磨（存在“待复核”轮次时不能再开新轮）。
- 首录需填写记录人、出墨速度、墨色层次、沉淀情况和评分；试纸、加水量选填。
- 首录后一律进入“待复核”：评分低于 85 或四项记录有缺失时，复核只能选择“重点观察”或“退回重开”，不能判“通过”。
- 复核人必须与原记录人不同，并填写处置（通过 / 重点观察 / 退回重开）。同一轮重复复核沿用首次复核结果。
- 未经复核的墨锭不会进入“已试磨”，因此不会被统计为已完成。
- “退回重开”或对已结案墨锭“重开试磨”后，旧轮次的首录与复核结果立即失效（保留在历史中并标注“已失效”），墨锭回到“待试磨”，需重新首录、重新复核。

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/items` | 墨锭列表（含轮次、推导状态） |
| GET | `/api/stats` | 状态统计 |
| POST | `/api/items` | 建档（固定为待试磨） |
| POST | `/api/items/:id/rounds` | 试磨首录，开新一轮 |
| POST | `/api/items/:id/review` | 双人复核并填写处置 |
| POST | `/api/items/:id/reopen` | 重开试磨，旧轮次失效 |
| POST | `/api/items/:id/logs` | 追加备注 |
| PATCH | `/api/items/:id` | 修改档案字段（不可改状态/轮次） |
